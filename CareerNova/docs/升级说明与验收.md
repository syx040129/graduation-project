## 已实现

- 简历附件退出公开静态映射。下载需 JWT，允许简历本人、管理员或接收该简历投递的企业；响应禁止缓存。头像、Logo、图片继续公开。下载按钮通过请求头携带 Token。
- JWT 每次请求查询账号状态及当前角色，禁用/删除账号的旧 Token 无法继续访问。权限不足时前端提示错误，保留仍然有效的登录状态。
- 投递验证在线岗位、简历归属、重复投递、企业归属与处理状态；数据库唯一键冲突转换为明确的重复投递提示。
- 匹配接口支持可选 resumeId，并验证简历归属。返回四维得分、技能命中、缺失技能、semanticSource、reasonSource、source、executionNote。向量部分失败时统一重算两端本地向量。模型理由失败或空响应明确标注降级。
- 推荐缓存检查整批时效及简历更新时间，修复用用户 ID 查询简历 ID 的错误。简历变更使该用户推荐失效；岗位变更使所有推荐批次失效。读取时过滤下架或删除的岗位。单次匹配和投递不混入推荐缓存。
- 简历解析只生成预览，不覆盖字段、技能或经历。确认后进入编辑页，补齐空字段、合并技能、核对后保存。修复解析结果路由状态传递时的对象克隆问题，以及清空编辑字段不能持久化的问题。
- 分析建议可跳转并滚动到技能、简介、经历或基本信息区域。匹配页可选择简历直接投递，推荐和匹配页均可进入对应岗位模拟面试。
- 简历优化禁止凭空补充事实。规则实现移除虚构的 30% 性能提升、未使用的岗位技术和未经证实的能力描述；模型提示词明确约束事实与数据。

## 历史专项验证（2026-10-08）

后端：`cd backend` 后执行 `mvn test`。前端：`cd frontend` 后执行 `npm run type-check` 和 `npm run build`。

本次结果：21 项后端自动化测试通过，前端类型检查与生产构建通过，6 组本地 MySQL 接口验收通过。

本地接口验收使用真实 MySQL 和独立的 Mock 后端进程。启动：

```powershell
cd backend
mvn spring-boot:run '-Dspring-boot.run.arguments=--server.port=8081 --ai.mock=true --ai.enabled=false --spring.ai.openai.api-key=not-configured'
```

另一个终端从项目根目录执行：

```powershell
node scripts/smoke-upgrade.cjs
```

脚本默认连接 localhost:8081/api，使用 admin/company/company2 演示账号，创建独立测试求职者、简历和岗位，并在 finally 中通过 API 清理测试业务记录。会刷新推荐缓存、留下正常操作日志以及上传测试附件；建议在本地演示库运行。可使用 SMOKE_API 和 SMOKE_PASSWORD 环境变量调整连接与演示密码。

验收项目：解析不覆盖；所选简历匹配与真实来源；匿名和未接收投递企业不能下载附件；发布→投递→企业处理→求职者查看；重复投递和跨企业请求被拒绝；简历/岗位变更后更新与下架过滤；禁用账号后旧 Token 失效。

浏览器验证：推荐页新增面试入口；匹配页显示本地向量说明、权重、简历选择与直接投递；跳转模拟面试后正确预选原岗位。

## 使用与边界

无需执行数据库迁移，也不需要重新导入 schema.sql/data.sql。正常运行仍按 README 启动；本次验收使用的 8081 是独立测试端口，默认服务端口仍为 8080。

推荐针对最新创建的简历生成，匹配与投递可独立选择简历。岗位变更采用全批次失效，适合当前演示规模；大规模运行时可改为版本或事件驱动失效。缓存不持久化模型执行来源，需要本次来源时进入匹配分析页重新计算。

真实外部模型未在本次验收中联网调用；通过自动化测试模拟成功、失败、非法向量及理由降级。模型提示词约束不能替代用户事实核对，优化结果仍需确认。

该次升级时有大体积 bundle 和静态/动态路由混用提示；最终收尾构建仅复现超过 500 kB 的 chunk 提示。最新验收及既有阻碍见 [项目总文档](项目总文档.md)。
