## 完成内容

安装并应用 frontend-design、ui-ux-pro-max、web-design-guidelines、webapp-testing。依据专业招聘平台的页面呈现要求，保留既有业务接口，重做首页、求职者导航、登录注册、企业/管理端公共框架；统一职位、简历、推荐、面试和后台页面样式。

推荐页将摘要、维度、技能和理由分层；简历分析先显示建议，再显示雷达图。移动导航、页面错误重试、键盘焦点与减少动态效果支持已补齐。首页统计来自后端，不使用虚构营销数字。

路由采用按页动态加载，图标/组件按实际用量注册，ECharts 仅加载所需图表类型。主入口 JS 从约 2551.52 KB 降到约 759.01 KB，图表资源独立按需加载约 537.37 KB。构建仍有大依赖 chunk 超过 500 KB 的体积提示，不影响构建通过，未通过提高告警阈值隐藏提示。

修复本地生产预览 5174 端口登录失败：SecurityConfig 从 app.cors.allowed-origins 读取白名单，该属性支持 CORS_ALLOWED_ORIGINS 环境变量。已验证允许的预览来源返回 200，未列入白名单的来源返回 403。

## 预览与复现

预览启动后的地址：http://127.0.0.1:5174。开发服务默认：http://localhost:5173；地址不代表当前后台服务正在运行。

在 frontend 目录执行 npm run build，然后 npm run preview -- --port 5174；backend 目录使用 README 中显式 Mock 启动命令，包含 spring.ai.openai.api-key 的非真实占位值。后端本次为了可重复验证，通过进程环境变量使用 AI_ENABLED=false、AI_MOCK=true，没有修改 .env.local 中的模型密钥或用户配置。

从项目根目录执行：

```powershell
python frontend/scripts/ui_smoke.py --base-url http://127.0.0.1:5174
python frontend/scripts/ui_interactions.py --base-url http://127.0.0.1:5174
```

Python 需安装 Playwright，电脑需安装 Chrome。图片预览位于 docs/ui-preview；原先的前端 ZIP 备份已随 backups 删除，不能再使用该路径恢复源码。界面规范现见 [界面设计规范](界面设计规范.md)。
