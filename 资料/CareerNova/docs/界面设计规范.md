# CareerNova UI 设计规范

> 文档更新：2026-10-08。文件名与引用按当前目录同步；验收记录标注的是历史验证，本轮未重新执行业务测试。 总入口：[项目总文档](项目总文档.md)。

## 用户与任务

面向求职者、企业招聘者与平台管理员。界面首先帮助用户找到岗位、完成投递、处理招聘事项，再呈现辅助分析。沿用“智聘”中文品牌，CareerNova 用于产品署名。AI 仍作为功能和结果来源标识，避免宣传文案与视觉装饰主导页面。

## 视觉决策

- 品牌蓝 #3159D8：主操作、导航选中、可点击的重要信息。
- 页面底色 #F6F8FB；表面 #FFFFFF；首页背景 #EDF3FB。
- 正文 #253245；辅助文字 #647185；边界 #E2E7EF。
- 成功 #187A66；警告 #AC690D；错误 #C94444，必须配文字或图标。
- 字体采用本地 Microsoft YaHei UI、PingFang SC、Noto Sans CJK SC，不依赖在线字体。
- 首页标题 36–50px，页面标题 24–28px，模块标题 17–24px，正文 14–16px，辅助文字 12–13px。
- 按钮/输入框圆角 7px；内容卡片 10–12px。默认不用阴影，浮层才使用轻阴影。
- 间距以 4/8px 为基础，模块间 24–42px，桌面内容宽度 1200px。

## 页面结构

首页：左侧职位搜索与真实岗位数量，右侧求职准备入口；下方按类别浏览真实岗位。登录后呈现个人推荐。删除与当前任务无关的滚动数字、营销渐变和功能宣传墙。

求职者：顶部导航、主体、简洁页脚。移动端使用展开菜单。职位列表保留筛选和分页，并将页码存入 URL。岗位卡片突出职位、薪资、企业、地点、经验和技能。

推荐：先呈现岗位与评分，再展示维度、技能和理由。不能把职位、维度、技能、理由和四项操作挤入一行。分数是匹配评分，不是录用概率。

简历分析：总评分与维度在左，优势、改进建议与方向在右，雷达图后置。简历编辑保留结构化分组和原有保存接口。

企业与管理员：共享 WorkspaceLayout，白色侧栏、当前位置、账号菜单、内容区域。企业招聘操作与管理表格保留现有业务行为。移动端侧栏关闭时不可获得键盘焦点。

登录注册：共享 AuthShell，品牌说明与表单分栏；手机只显示表单。演示账号折叠展示。企业注册链接带 role=COMPANY，进入后默认选中企业。

## 组件与实施

- src/styles/index.css：颜色、排版、交互焦点、Element Plus 主题。
- src/styles/pages.css：旧业务页面向统一规范迁移的显式样式层。
- PositionCard.vue：首页岗位展示，真实岗位详情链接。
- AuthShell.vue：登录和注册的公共布局。
- WorkspaceLayout.vue：企业和管理员的公共布局。
- src/plugins/ui.ts：仅注册项目中使用的组件/图标。
- scripts/generate-ui.mjs：添加新组件后可重新生成注册列表；build/predev 自动执行。

业务页面迁移完成后，新增页面应使用上述变量及组件，逐步把 pages.css 中对应页面规则移到页面自身，不再引入新的重复主题。

## 可访问性与运行要求

导航使用真实链接；操作使用按钮；表单提供标签；图标按钮提供名称；焦点可见。图表提供文本描述，数字保留相应数据展示。尊重 prefers-reduced-motion；手机避免横向溢出；抽屉和聊天面板尊重安全区域。

加载、无结果、请求失败有独立反馈。失败状态允许重试。未经验证不展示成功、录用率等推断数字。生产构建同时执行类型检查。
