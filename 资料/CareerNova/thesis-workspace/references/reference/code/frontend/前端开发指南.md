# 前端开发指南

> 文档更新：2026-10-08。文件名与引用按当前目录同步；验收记录标注的是历史验证，本轮未重新执行业务测试。 总入口：[项目总文档](../docs/项目总文档.md)。

当前项目为 Vue 3 + TypeScript + Vite + Element Plus，页面已接入 Spring Boot 接口。界面规范见 [界面设计规范](../docs/界面设计规范.md)，交付状态见 [项目总文档](../docs/项目总文档.md)。

## 运行与检查

```powershell
cd frontend
npm ci
npm run dev
npm run type-check
npm run build
npm run preview -- --host 127.0.0.1 --port 5174
```

后端按 [README](../README.md) 的显式 Mock 命令启动；完全空密钥的默认启动当前未通过。开发默认 5173，`/api` 代理到 8080。build 自动生成组件注册列表、执行 vue-tsc，再构建生产资源。preview 使用同一 API 代理，后端需保持运行。

## 页面与组件

- 求职者使用 UserLayout；企业、管理员通过各自布局封装共用 WorkspaceLayout。
- 登录注册使用 AuthShell；首页使用 PositionCard。
- 前端页面路由均采用动态导入。图表按 Bar/Line/Pie/Radar 使用范围注册。
- 全局基础样式在 styles/index.css，现有业务页面的统一呈现规则在 styles/pages.css。
- 新页面只使用语义颜色变量，保持显示密度、空态和交互反馈一致。

## UI 组件与图标

模板中的 Element Plus 组件及动态图标均全局注册，无需页面反复导入。全局注册清单由 scripts/generate-ui.mjs 扫描源文件生成，dev 启动前与 build 自动更新。开发服务器运行期间添加新组件时执行：

```powershell
node scripts/generate-ui.mjs
```

注册列表不再包含所有未使用图标；不要直接编辑 plugins/ui.ts。

## API 与状态

使用 src/api 下的函数，不在页面裸用 axios。请求层解包 Result 的 data、附加 JWT。401 由入口统一清除 Pinia/localStorage 并跳到登录页，保留原始地址；403 只显示权限错误。

分页 PageResult 为 records、total、page、size，page 从 1 开始。职位列表页码和筛选项同步 URL，刷新可以恢复。编辑表单调用原有接口，禁止用静态假数据替代后端结果。

## 图表

使用 useChart：自动创建和销毁图表，随数据与 ResizeObserver 更新，尊重减少动态效果设置。图表启用文本描述。新增其他图表类型需在 utils/echarts.ts 注册相应模块。

## 浏览器验证

安装 Python Playwright，电脑需安装 Chrome。确保前端和后端正在运行并有 README 中的演示账号：

```powershell
python frontend/scripts/ui_smoke.py --base-url http://localhost:5173
```

该命令应从项目根目录执行。它登录三角色，验证桌面/手机路由、搜索、分页、失败重试、移动菜单与聊天收起。测试不发布岗位、不提交投递、不删除业务数据；部分 GET 业务接口会更新浏览数或推荐缓存。
